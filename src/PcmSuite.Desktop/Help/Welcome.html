Welcome to PcmSuite

PcmSuite puts the three jobs of tuning a GM PCM in one window: Flash (read and write the PCM), Logger (record what the engine is doing) and Tuner (edit the calibration). A vehicle project ties them together, so everything about one car is kept in one folder.

This prototype is built on PCM Hammer. The Flash and Logger tabs are PCM Hammer's own screens; the Tuner is PcmSuite's own. Their help is under Flash and Logger in the topic list above.

Looking for something? Type a question or a few words in the search box above (for example "save the file" or "protected xdf"): it searches all the help pages and takes you to the matching section. The How do I...? list under it has the common tasks.

What each tab does

  • Flash - connect to the PCM, read its contents to a BIN file, write a BIN back, verify.
  • Logger - choose the parameters to watch, see them live, and record them to a CSV file.
  • Tuner - open a BIN with its XDF, edit tables, compare with another BIN, correct the checksums and save.
  • Logs - the crash logs the program left behind: read one, copy it, delete it.
  • Help - this page, PCM Hammer's help for Flash and Logger, and the Tuner manual.
  • Credits - who made what.
  • About - which build you are running, and a button that copies the details for a bug report.

A typical session

  1. Make a project (Tuner, menu, Project, Projects..., New project...). Give it a name and the vehicle details, and say where the tune starts.
  2. Read the PCM on the Flash tab. Save the read in the project's reads folder (the Flash tab shows the path, and it is on the clipboard). The Tuner notices the new file and offers to open it. The first read becomes the project's untouched base.
  3. Edit in the Tuner. Changes against the base are marked automatically. Save As writes a new numbered file in the project's edits folder, with the checksums corrected.
  4. Write it back on the Flash tab. After a good Save As, the Tuner offers Send to Flash.
  5. Log a drive on the Logger tab with one of the ready-made tuning profiles. Recordings go to the project's logs folder, and the Tuner's VE wizard can read the newest one and suggest corrections.

One adapter at a time

Only one tab can use the adapter at a time. Leaving the Flash tab releases the adapter. The Logger stays connected when you move between the Logger, the Tuner and Help, so the Tuner's Live trace can follow the engine; going to Flash, Logs, About or Credits disconnects it. Flash operations that are running (read, write, verify) cannot be interrupted by switching tabs: wait for them to finish or cancel them first.

Kernel files

Reading and writing need PCM Hammer's PCM-side kernel files (Kernel-*.bin). PCM Hammer only allows them to be redistributed inside its official releases, so PcmSuite does not include them. Copy them from an official PCM Hammer release into the folder that contains PcmSuite.exe. If they are missing, the status bar at the bottom says so.

Before you flash

  • Keep the original read. Every project keeps its first BIN untouched in reads.
  • Only flash a file that Save As reported as valid. If it says the checksums could not be fixed, do not flash it.
  • Use a stable power supply (a battery charger) for the whole write, and do not interrupt it.
  • This is a prototype. Edits are suggestions you are responsible for; nothing here can know whether a tune is safe for your engine.

Reporting a problem

Open the About tab and press Copy details for a bug report. It copies the version, the PcmSuite and PCM Hammer builds (commits), and your system, so paste it into your message and say what you were doing.

If the program closes by itself, it leaves a crash log. The Logs tab lists them: pick one to read exactly what it holds, press Copy and paste it into your message (or Open folder to attach the file). You can delete a log you no longer need. A crash log holds the error, where in the program it happened and the build details. It can include file paths (and so your Windows user name), but never the contents of your BIN files.
